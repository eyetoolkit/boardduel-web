What stays the same when the game changes.

One implementation wearing five boards. These three rules are the build spec — every draft obeys them, and the shipped engines should too.

The certainty ladder

Each game computes exactly what it can and says so. The UI never bluffs: a hint that's arithmetic is labeled arithmetic, a verdict that's bounded says "within the horizon."

The cast rules

Fill carries allegiance: dark is you, paper is them — four boards running. Chess bends it on purpose, because White moves first. Pieces never wear faction color; ember and teal stay HUD furniture. Gold is spent once per page, on the one thing that game is about.

03 — WHAT THE SERVER ACTUALLY DOES

One door opens. Four don't.

Verified against the live site today — not assumptions. This homepage ships as a draft alongside five game drafts; the pills on the wall are its roadmap.

P0 · production

Four dead links

/games/gomoku/ returns 404. /games/reversi/ — page and engine, both 404. /games/chess/ — page and engine, both 404. Connect4's page loads, but its ai.js 404s, so no match can start. Only tictactoe is fully alive.

Ship engines first, pages second, nav last — per game, in that order. The drafts pin the interface contract: newGame · applyMove · chooseMove · undo.

P1 · distribution

The nav promises five, the server ships one

Every game draft's switcher links five games; the live homepage links one. A five-game nav over one game is a promise the server can't keep — and players meet the 404 first, not the game.

The switcher ships with the third working engine, not the first — or it adopts the wall's pills and says which links are real.

P2 · pattern

No costume for thinking

The two live engines fake thinking delays — baseByDiff*2.2 + Math.random()*500 and *1.8 + Math.random()*600. The wall holds itself to the same standard in reverse: no screenshots, no mocks — every thumbnail replays from engine data.

Real engines at these depths answer in milliseconds; the board's own turn is the pacing. Delete the sleep calls, not the honesty.

04 — DESIGN NOTES

What the homepage adds to the family.

a
The wall is a directory, not a dashboard. Five thumbnails, five true pills, five deep links into the drafts. It answers "what is this place and what works" in one screen — nothing summarizes what a click can show.
b
Gold marks the door. The family's scarcest color goes to the one game the server can finish. Four 404 pills stay mute and dashed — missing things don't get to glow.
c
404, twice. The wall holds exactly 404 squares — 225 + 9 + 42 + 64 + 64 — and four links that 404. The number was a gift; the strip keeps it in plain sight.
d
The arc is the history. Framed battlefield → open hash → punched cage → flat plate → true checker. Five boards, one grammar — the silhouette section is the family's visual memory, stated once, here.
e
The contract is the build spec. Three screens, a certainty ladder, cast rules — the "what stays the same" section is written for the engineers who ship the four missing engines, not just for readers.
f
Every thumbnail is replay-verified. Build-time assertions: 35 gomoku drops, 9 tictactoe marks with no winner, 35 connect4 drops ending on the diagonal, 64 reversi discs counted at 39–25, 2 kings on the chess board. If the data lies, the build fails.

Open questions

  • Do the pills graduate? When an engine ships, "page 404" could become "engine in review" — status now, ETA later, or keep the wall binary: live or not.
  • One lobby or five? Should the homepage own a universal quick-match queue across all five games, or deep-link each game's own lobby? One queue is simpler; five lobbies match the drafts.
  • The 404 easter egg: strip-stated (as drafted), or view-source only? Saying it out loud is on-brand — but it's also the kind of joke that ages.
