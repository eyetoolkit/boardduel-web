Rematch: loser drops first. Unlike tictactoe's coin flip, connect4's first disc carries a proven edge — the loser should open. One line of product logic, backed by 90 solver games.
05 — WHAT THE SERVER ACTUALLY DOES

Three findings. One is a production outage.

Verified against the live site and the shipped page today — not assumptions. This draft's engine data is produced by a local solver specifically because finding #1 below is true.

P0 · production

The engine file is missing

The connect4 page loads, but its module imports ./ai.js — which returns HTTP 404. The module throws on import, so "Play the engine" never starts for any visitor. The page already pins the interface: newGame · applyMove · chooseMove · COLS.

Deploy the engine — the contract is already written by the page. Until then the lobby card must say "engine offline," not hide the failure.

P1 · distribution

The nav is ahead of the deploy

The ARENA family switcher lists five games. In production the homepage links only tictactoe — and the gomoku page itself is a live 404. The family is a roadmap; one game is shipped.

Ship the finished engines first, then let the nav follow. A switcher pointing at dead pages is worse than no switcher.

P2 · theater + emoji

Costume where confidence belongs

The thinking delay is faked again — baseByDiff*1.8 + Math.random()*600 (~2s on hard). And the marks are emoji (🔴🟡) in the enhancer. The drop animation is the real feedback.

Drop the costume: render solid discs, and let Punisher answer instantly. A perfect player replying without hesitation is the character.

06 — DESIGN NOTES

What connect4 adds to the family.

a
Fill carries allegiance again. Four boards in, the rule is settled: black/white stones, X/O marks, dark/paper checkers — pieces stay neutral of faction color; ember and teal remain clock-and-chip furniture.
b
Gold is the connector, once. Gomoku rings the five, tictactoe strikes the three, connect4 links the four. Same token, same scarcity, drawn a single time per game.
c
Three silhouettes, one token set. Framed battlefield → open hash → punched cage. The board furniture changes per game; the colors and the rule "pieces carry the game" never do.
d
Coordinates collapse to a column. Gravity erases the row choice, so the recorder and ruler are column-only — the most reduced notation in the family, and the right one.
e
Certainty scales to gravity. Tictactoe proved exact verdicts; connect4 proves column verdicts at a bounded search depth. The panel copy says "within the horizon" so it stays honest as the horizon moves.
f
Every number is solver-verified. The 90 games, the 89 hard wins, the 0 draws, the sharp mid position and its single winning column — produced by the bitboard solver in this session, because the live engine is absent.
